# Bundled fonts

Noto Sans CJK Regular and Bold TTC, unmodified copies from the installed
Ubuntu/Debian `fonts-noto-cjk` package `1:20240730+repack1-1build1`.

Upstream: https://github.com/notofonts/noto-cjk

License: SIL Open Font License 1.1. The package's full copyright/license
notice is preserved in `resources/licenses/NotoSansCJK.txt` and shipped
beside the executable.

Both collections are embedded in the executable and registered privately
with MyGo's native text engine. They are not installed into the user's
Windows font directory. Regional families used by the UI are Noto Sans CJK
TC, SC, JP and KR; all include Latin/English characters. Bold is rendered
from the bundled Bold faces, not by enlarging Regular text.
